# Data

Place the FabricSpectra files (Kim and Chi, ICASSP 2026) in `data/FabricSpectra/`:

```
data/FabricSpectra/
  train_data.npy
  train_multi_label_classification_label.npy
  train_composition_label.npy
  test_data.npy
  test_multi_label_classification_label.npy
  test_composition_label.npy
```

Each spectrum has two channels of 200 points over 960–1660 nm: absorbance
first, then reflectance. The data are not redistributed here.
